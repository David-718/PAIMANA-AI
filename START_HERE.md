# START HERE — SIH26103 PAIMANA AI Prototype

## What this package is
An integrated demonstration of an AI-powered Predictive Analytics, Early Warning and Decision-Support System for infrastructure project monitoring.

## Main capabilities
1. Portfolio dashboard
2. Cost escalation prediction
3. Schedule/time overrun prediction
4. Project risk scoring
5. Early warning queue
6. Sector benchmarking
7. Explainable cost/risk drivers
8. Prescriptive intervention recommendations
9. Project drill-down
10. Project Intelligence Assistant
11. Statistical-vs-ML model comparison module
12. CUF and additional-variable assessment
13. Documentation and deployment notes

## Run
See `README.md` and `docs/DEMO.md`.

Typical backend:
- Windows: `run_backend.bat`
- Linux/macOS: `run_backend.sh`

Then open the frontend as documented in README.

## Important
The dashboard is a prototype. Do not describe derived/demo scores as official Government of India risk scores. Production use requires authorised PAIMANA/OCMS data, historical labels, validation, governance and security hardening.


## New integrated UI features
- Prototype login accepts any username/password and routes to the selected role dashboard.
- Management, Admin and Project Officer have distinct dashboard content.
- Left-side **Projects** menu contains the descriptive project portfolio.
- Left-side **Early Warnings** menu opens a dedicated prioritised warning screen.
- Management has a **＋ Add Project** action that adds and analyses a project in the current session.
