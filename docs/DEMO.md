# 5-Minute SIH Demo Script

### 0:00 — Problem
“PAIMANA already provides descriptive project monitoring. Our solution adds a predictive and prescriptive layer that tells officers which projects need attention before risks become severe.”

### 0:45 — Portfolio
Show:
- projects monitored
- high-risk projects
- early warnings
- original vs revised portfolio cost
- predicted final portfolio cost

### 1:30 — Risk register
Search/filter High risk. Click a project.

Say:
“The score is explainable. We are not only saying HIGH; we show why: cost escalation, progress lag, milestone pressure, contractual exposure and implementation issues.”

### 2:30 — Prescriptive action
Point to the recommendations:
- critical-path recovery
- escalation-driver validation
- milestone accountability
- contract/claim review
- issue-resolution plan

### 3:15 — Analytics
Open Analytics:
“This changes monitoring from a list of projects into portfolio intelligence. Officers can benchmark sectors and focus scarce review capacity.”

### 4:00 — AI assistant
Ask:
“Which projects are high risk?”
“What is the portfolio cost?”
“Which projects face delays?”
“What actions should officers take?”

### 4:40 — Production story
“The supplied demo snapshot does not contain every CUF field required for a validated model. Therefore this prototype clearly labels derived fields and treats the risk index as a demo indicator. With authorised OCMS/PAIMANA history, the same API can train leakage-safe statistical and ML models and compare their predictive performance.”

### Judge takeaway
Predictive + explainable + prescriptive + portfolio-level + open-source + deployment-ready architecture.
