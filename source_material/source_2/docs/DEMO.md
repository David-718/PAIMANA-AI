# 5-minute hackathon demo flow

1. Start FastAPI and React.
2. Open the dashboard.
3. Show portfolio KPIs.
4. Click a high-risk project.
5. Explain the risk score, predicted final cost, predicted delay, drivers and recommended actions.
6. Show early-warning alerts.
7. Ask the Project Intelligence Assistant: “Which projects are high risk?”
8. Explain that the current prototype uses a transparent baseline and can be upgraded with historical OCMS/PAIMANA data and evaluated against conventional statistical methods.
9. Emphasise that the unique value is predictive + prescriptive monitoring, not just data entry/reporting.

## Judging points to mention
- Early warning before overruns become severe.
- Explainable drivers instead of a black-box score.
- Prescriptive actions for officers.
- Portfolio-level benchmarking.
- Role-based access.
- API-first architecture.
- Open-source stack.
- Clear separation between synthetic demo data and authorised government data.
